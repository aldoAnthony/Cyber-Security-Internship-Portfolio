# Cybersecurity Internship Portfolio 🛡️

I'm a cybersecurity intern with over ten years in hands-on technical roles and a background in data engineering. These projects come from my LOG(N) Pacific internship, where I worked in a live Azure environment with Microsoft Defender for Endpoint, Microsoft Sentinel, KQL and Tenable. Each one is written up end to end: what I set out to do, how I did it, what I found and what I'd do next.

## ⚠️ Vulnerability Management

- **[Vulnerability Management Programme Implementation](https://github.com/aldoAnthony/vulnerability-management-program)**
  Policy, authenticated Tenable scanning, CVSS-based prioritisation, remediation and rescans to verify.
- **[Programmatic Vulnerability Remediations (PowerShell, BASH & Shell Commands)](https://github.com/aldoAnthony/programmatic-vulnerability-remediations)**
  Scripted fixes for vulnerabilities and failed DISA STIG checks, each verified with a Tenable rescan.

## 🚨 Threat Hunting and Security Operations

- **[Threat Hunting Reports](https://github.com/aldoAnthony/threat-hunting-reports)**
  Multi-stage hunts across endpoint and cloud telemetry, written in KQL and mapped to MITRE ATT&CK.
- **[Incident Response: Honeypot Breach](https://github.com/aldoAnthony/incident-response-honeypot)**
  Built and logged a MySQL honeypot, wrote detections, then detected, contained and reported a live breach (NIST 800-61).

## 🧰 Tools I Used

Microsoft Defender for Endpoint · Microsoft Sentinel · KQL · Tenable · PowerShell · Microsoft Azure · MITRE ATT&CK · NIST 800-61
